# Neon Racer 🏁

O‘zbek tilidagi neon arcade poyga o‘yini. Uch qatorli yo‘lda rang-barang raqib mashinalarini quvib o‘ting, to‘qnashuvdan qoching va rekord ochko yig‘ing.

## O‘yin
- Raqib mashinasini quvib o‘tish: **+100 ochko**; yonidan yaqin o‘tish: qo‘shimcha **+25 ochko**.
- Vaqt o‘tishi bilan tezlik va raqiblar soni oshadi.
- To‘qnashuv o‘yinni tugatadi; rekord brauzer xotirasida saqlanadi.
- Ovoz tugmasi ovozni yoqib/o‘chiradi; **P** yoki **Esc** — pauza.

## Boshqaruv
- Kompyuterda: **← / →** yoki **A / D**.
- Telefonda: ekrandagi **CHAP / O‘NG** tugmalari yoki poyga yo‘lini chap/o‘ng тийшээ swipe хийнэ.
- Утасны vibration дэмжлэг браузер ба төхөөрөмжөөс хамаарна. Дэмждэг төхөөрөмж дээр мөргөлдөхөд богино чичиргээ, мөн дэлгэц сэгсрэх эффект гарна.

## GitHub Pages
Repository-ийн **Settings → Pages → Deploy from a branch → main → /(root) → Save**-г сонгоно. Pages нийтлэхэд бага зэрэг хугацаа орж болно.
